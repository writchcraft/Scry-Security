Incident summary

Five Windows failed logons are followed by a successful network logon for the same account and source.

Rule matches identify suspicious activity; they do not confirm compromise.

Affected scope

  • Hosts: windows-lab
  • Operating systems: windows
  • Accounts: alice
  • Source addresses: 192.0.2.11
  • Destination addresses: Unavailable

Observed evidence

  • 6 supporting events retained from 2 alert(s).
  • Event times span 2026-10-31T11:30:00+00:00 to 2026-10-31T11:30:05+00:00.
  • SCRY-AUTH-003: 6 supporting event(s); status new.
  • SCRY-AUTH-001: 5 supporting event(s); status new.

Analyst interpretation

The native LogonType is 3. Verify source ownership, failure codes and account history before interpreting the successful logon as account compromise.

Detection context

No additional host-policy context was recorded for these detections.

Possible false positives

  • Expired credentials, user mistakes, and authorised testing can explain this pattern.

Recommended defensive actions

  • Validate with the owner; apply rate limiting and review account protection if unauthorised.

ATT&CK references

  • T1110
